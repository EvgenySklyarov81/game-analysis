# Анализ продуктовых метрик и поведения пользователей в мобильной игре
*Примечание: проект является учебным, анализируемые данные — синтетические.*

Проект посвящен исследованию поведения игроков в мобильной игре-викторине. Главная цель — понять, как первоначальное обучение (знакомство с правилами игры) влияет на то, как быстро пользователи проходят ключевые этапы воронки и готовы ли они в итоге совершать покупки.

Исследование сфокусировано строго на когорте пользователей, зарегистрировавшихся в **2018 году** (размер группы после очистки — **19 926 уникальных игроков**).

---

## 🎯 Ключевые результаты и бизнес-выводы

### 1. Скорость прохождения игры (Влияние обучения)
* **Факт:** Игроки, прошедшие обучение, доходят до выбора уровня сложности за 6 часов (медиана), а необученные — быстрее, за 4.93 часа. Однако коммерческий шаг (от выбора сложности до покупки) обученные игроки делают практически мгновенно — **всего за 6 минут**! 
* **Аномалия:** У игроков без обучения обнаружена инверсия воронки: медиана времени до покупки (4.77 часа) меньше времени выбора сложности (4.93 часа). Это доказывает, что без онбординга пользователи движутся хаотично и могут заходить в магазин раньше, чем определятся с уровнем игры.
* **Надежность:** Разница в скорости доказана математически с помощью **критерия Манна-Уитни** (p-value < 0.05). Случайность полностью исключена.

### 2. Зависимость покупок от количества обучений
* **Факт:** Прохождение обучения — главный коммерческий водораздел игры. Завершение хотя бы одного цикла инструкций увеличивает шансы на покупку **почти в 10 раз (с 1.5% до 14.3%)**. Группа с 1 обучением принесла максимум денег — **1143 покупки**.
* **Надежность:** Связь доказана **критерием Хи-квадрат Пирсона** (p-value ≈ 0). Повторные прохождения туториала (2, 3 и более раз) экономически бессмысленны, а колебания процентов на малых выборках являются обычным случайным шумом.

### 3. Скрытый интерфейсный барьер
* **Факт:** Выявлено, что **6.96% пользователей (1386 человек)** повторно запускают обучение уже после того, как выбрали уровень сложности. Они используют инструкции как временную справку, так как путаются в механике главного экрана.
* **Рекомендация:** Продуктовой команде необходимо внедрить короткие контекстные подсказки (tooltips) на игровом экране, чтобы игрокам не приходилось заново перезапускать тяжелое обучение.

## 🛠 Технологический стек и инженерные решения

* **Инструменты:** Python, Pandas, NumPy, Matplotlib, SciPy.
* **Оптимизация памяти:** За счет настройки типов данных (`int16`, `int32`) и перевода текстовых полей в категориальный вид (`category`) вес таблиц в оперативной памяти **уменьшен на 84%**.
* **Технический аудит данных:** 
  * Проведен точечный анализ 133 ошибок форматирования дат.
  * Реализованы проверки на уникальность профилей и логический тест хронологии (отсутствуют действия пользователей до их регистрации).

## 📁 Структура репозитория

* `data/` — папка с исходными логами активности (`events.csv`) и логами покупок (`purchases.csv`).
* `game_analysis.ipynb` — интерактивный Jupyter-блокнот с пошаговым кодом, графиками и выводами.
* `environment.yml` — конфигурационный файл для развертывания среды через Conda.
* `requirements.txt` — файл зависимостей для сборки среды через стандартный pip.

## 🚀 Инструкция по локальному запуску
Скачайте репозиторий (или распакуйте ZIP-архив) и откройте терминал/консоль в папке проекта.
### Вариант 1: Запуск через Anaconda / Conda (Рекомендуемый)
Откройте терминал (или Anaconda Prompt) в папке проекта и выполните команды:
1. Создание изолированного окружения:
   ```bash
   conda env create -f environment.yml
   ```
2. Активация окружения:
   ```bash
   conda activate game_analysis_env
   ```
3. Запуск среды:
   ```bash
   jupyter lab
   ```
4. Запуск блокнота:  
   В открывшемся окне браузера в левой панели дважды кликните по файлу `game_analysis.ipynb`, чтобы открыть блокнот.

### Вариант 2: Запуск через стандартный Python (без Conda)
Откройте терминал / командную строку в папке проекта и выполните:
1. Создание виртуального окружения:
   ```bash
   python -m venv venv
   ```
2. Активация окружения:
   * На Windows: `venv\Scripts\activate`
   * На macOS/Linux: `source venv/bin/activate`
3. Установка всех необходимых библиотек:
   ```bash
   pip install -r requirements.txt
   ```   
4. Запуск среды:
   ```bash
   jupyter lab
   ```
5. Запуск блокнота:  
   В открывшемся окне браузера в левой панели дважды кликните по файлу `game_analysis.ipynb`, чтобы открыть блокнот.
