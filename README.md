## 🚀 Инструкция по локальному запуску

### Вариант 1: Запуск через Anaconda / Conda (Рекомендуемый)
Откройте терминал (или Anaconda Prompt) в папке проекта и выполните команды:
1. Создание изолированного окружения:
   ```bash
   conda env create -f environment.yml
   ```
2. Активация окружения:
   ```bash
   conda activate game_analysis_env
   ```
3. Запуск среды:
   ```bash
   jupyter lab
   ```
4. Запуск блокнота:  
   В открывшемся окне браузера в левой панели дважды кликните по файлу `game_analysis.ipynb`, чтобы открыть блокнот.

### Вариант 2: Запуск через стандартный Python (без Conda)
Откройте терминал / командную строку в папке проекта и выполните:
1. Создание виртуального окружения:
   ```bash
   python -m venv venv
   ```
2. Активация окружения:
   * На Windows: `venv\Scripts\activate`
   * На macOS/Linux: `source venv/bin/activate`
3. Установка всех необходимых библиотек:
   ```bash
   pip install -r requirements.txt
   ```   
4. Запуск среды:
   ```bash
   jupyter lab
   ```
5. Запуск блокнота:  
   В открывшемся окне браузера в левой панели дважды кликните по файлу `game_analysis.ipynb`, чтобы открыть блокнот.
